ESP32-S3-4848S040 · Interfaz Portátil

Firmware del panel cuadrado 480×480 conectado al backend consolidado de Ubuntu/WSL.

Hardware objetivo

ESP32-S3 N16R8

LCD ST7701, táctil GT911, flash QIO 16 MB y PSRAM OPI 8 MB.

Contrato backend

GET /api/device/v1/health

El firmware exige HTTP 200 para declarar disponible el backend y conserva la confirmación humana para las órdenes.

CI remoto

Contrato + compilación

Ver workflows, checks y artefactos. El smoke HTTP del backend se ejecuta solo cuando BACKEND_HEALTH_URL está configurado.

Evidencia física E2E

  1. El workflow manual physical-e2e-panel requiere run_physical_e2e=true.
  2. GitHub debe tener un runner self-hosted con la etiqueta panel-4848s040.
  3. El runner debe disponer de include/local_config.h sin versionarlo.
  4. La prueba carga por USB y exige evidencia serial de arranque, inicialización ST7701, Wi-Fi y GET health -> 200.
  5. Finalmente consulta /health del propio ESP32 y exige ok=true, wifi=true y backend=true.

CI hospedado no puede tocar el panel físico. El estado de “Physical E2E PASS” solo puede originarse en el runner self-hosted con el dispositivo conectado. La legibilidad óptica y la interacción táctil requieren evidencia directa adicional.
